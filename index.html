📊 Dashboard Structure

The Power BI workbook is organized into 3 operational reporting views:

🏠
1. Home Page
31 Visual Components

Executive summary of enquiry throughput and booking confirmation metrics.

  • Total Enquiry volume & confirmation ratios
  • Resolutions by MJK (Mohd Jasim Khan) vs. Aniket
  • High-level action status distributions
  • Key operations KPI indicators
⚡
2. Action Page
32 Visual Components

Operational failure breakdown and vendor exception hotspots.

  • Booking failure distribution by reason
  • Hotel chain error rates (Travelodge, Holiday Inn, etc.)
  • Advanced slicers for Date, Agent, and Chain
  • Exception handling prioritization
📋
3. Detail Page
25 Visual Components

Granular recurring failure patterns and timeframe trend monitoring.

  • Recurring failure patterns over time
  • Failure rate shift across shift periods (SOD to EOD)
  • FreshDesk ticket references
  • Daily operational status trends

💡 How to Open & Refresh in Power BI Desktop

  1. Download the repository ZIP or the .pbix file above.
  2. Open CTM Dashboard Open Enquiries.pbix in Power BI Desktop.
  3. To link to the Excel file on your machine: Click Home → Transform Data → Data Source Settings → Change Source and point to your local Excel file.
